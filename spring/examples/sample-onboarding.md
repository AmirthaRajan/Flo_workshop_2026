# Sample project onboarding

Install Java 17 or newer. The project ships with the Maven wrapper, so no separate
Maven install is needed. Start the development server with `./mvnw spring-boot:run`
(or `.\mvnw.cmd spring-boot:run` on Windows) and open http://localhost:8080.

The team reviews changes through pull requests. Ask one teammate to review a
change before merging it into the main branch.
